# Publicar comunicados

En Pages CMS, abrí **Comunicados del club → Crear**. Completá título, fecha, resumen opcional, firma y texto. La hoja con escudo y colores se genera automáticamente. Activá **Publicar en la web** y guardá cuando esté confirmado. Los borradores no se publican. GitHub Pages reconstruye el sitio tras guardar.

El archivo público está en `/articulos/comunicados/`, enlazado desde Artículos en ambos idiomas. Conserva los documentos oficiales en español, sin traducción automática. Las publicaciones se ordenan por fecha descendente. No renombres el archivo tras compartir su enlace.

Cada comunicado permite compartir el enlace por WhatsApp, copiarlo y preparar una imagen PNG de 1080 × 1920 para historias. Si el contenido excede el espacio disponible, se recorta con puntos suspensivos y «Seguir leyendo». Descargar no publica en redes. En Instagram hay que subir la imagen y agregar el sticker Enlace pegando la URL del comunicado. El botón Compartir imagen aparece solo si el navegador permite compartir archivos, y el sistema decide qué aplicaciones ofrecer.

Las imágenes de referencia no se publicaron como comunicados: son ejemplos visuales sin una fecha de emisión confirmada. Para probar, creá un borrador con texto de prueba y verificá el formato antes de publicar contenido oficial.


## Tradução para português

Em **Comunicados em português**, crie uma entrada com o mesmo nome-base do arquivo do comunicado em espanhol, sem a extensão `.md`, por exemplo `2026-11-10-citacion-a-asamblea-general-extraordinaria`. Use a mesma data e o mesmo estado de publicação; preencha título, resumo e texto em português. O nome idêntico vincula os dois endereços, e as bandeiras passam a alternar entre as versões. Traduza também os comunicados futuros seguindo esse procedimento.
